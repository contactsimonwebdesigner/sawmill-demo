# HVOZD. — DEMO moderní české pily
Kompletní statický web pro portfolio, pouze HTML, CSS a JavaScript.

## Spuštění
Otevřete index.html v prohlížeči. Není potřeba instalovat žádné závislosti.
## GitHub Pages
Vytvořte repozitář, nahrajte obsah složky HVOZD-SAWMILL do rootu, v Settings → Pages vyberte Deploy from a branch → main → / (root).
## Co obsahuje
- Vlastní výraznou vizuální identitu moderní pily
- 34 skutečných ilustračních fotografií v assets/images ve WebP
- Katalog 8 demonstračních produktů s kategoriemi a cenami
- Interaktivní přepočet objemu m³ a ceny podle dřeviny, rozměrů, množství a úprav
- Galerii, filtry, fullscreen lightbox, klávesnici a mobilní navigaci
- DEMO formulář, který skutečně nic neposílá: vytvoří text ke kopírování
- FAQ, orientační postup zakázky, responzivní design
## Upozornění
HVOZD. je fiktivní značka, není spojena s pilou Onšov. Fotografie Pexels jsou pouze ilustrační a nevydávají se za realizace či zaměstnance této značky. Ceník je čistě ilustrační, bez DPH a dopravy. Texty, informace i údaje jsou demonstrační. Neexistuje žádné potvrzení skutečných zakázek ani rezervací.
## Úpravy
Obsah sortimentu a galerie je v app.js. Barvy a layout jsou ve styles.css.
